Expense Tracker Web Application

A full stack web application designed to help users manage and organize their expenses.

Tech Stack:
    - Frontend: React, Vite, JavaScript
    - Backend: Node.js, Express.js
    - Database: PostgreSQL (planned integration)
    - Version Control: Git an Github

Project status: In Development

Planned Features:
    - Add, edit, and delete expenses
    - Organize expenses by category
    - Store expense recrods in PostgreSQL
    - Connect the frontend and backend using RESTful APIs
